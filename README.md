# Pet & House Sitting Board- SitConnect

## Tech Stack

- React Native + Expo
- SQLite (Expo)

## How to Run

1. npm install
2. npx expo start
3. Scan QR code using Expo Go (Android)

## Features

- Role selection
- CRUD for listings
- Browse + filter listings
- Save listings
- SQLite persistence
